# Neon Space Arena — политика конфиденциальности

Публичная статическая страница политики конфиденциальности Android-игры Neon Space Arena.

- Разработчик: Amoristik.
- Контакт: mr.amoristik@gmail.com.
- Идентификатор приложения: `com.amoristik.neonarena`.
- Сайт: https://amoristik.github.io/neon-space-arena-privacy/

В репозитории находятся только файлы публичной страницы. Исходников игры, закрытых ключей и паролей здесь нет.

GitHub Pages публикует `index.html` из корня ветки `main`. Страница не использует JavaScript, внешние шрифты, рекламу или аналитику. Обработка технических данных хостингом GitHub описана в политике.
