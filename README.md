# Neon Space Arena — политика конфиденциальности

Публичная статическая страница политики конфиденциальности Android-игры Neon Space Arena.

- Разработчик: Amoristik.
- Контакт: mr.amoristik@gmail.com.
- Идентификатор приложения: `com.amoristik.neonarena`.
- Сайт: https://amoristik.github.io/neon-space-arena-privacy/
- English: https://amoristik.github.io/neon-space-arena-privacy/en.html

В репозитории находятся только файлы публичной страницы. Исходников игры, закрытых ключей и паролей здесь нет.

GitHub Pages публикует `index.html` (русский), `en.html` (английский) и общий `styles.css` из корня ветки `main`. Ссылка для Play Console остаётся прежней; вверху обеих страниц есть переключение «Русский / English», работающее без JavaScript. Страницы не используют внешние шрифты, рекламу или аналитику. Обработка технических данных хостингом GitHub описана в политике.
